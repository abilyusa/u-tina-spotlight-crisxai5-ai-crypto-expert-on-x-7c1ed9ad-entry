## How it works

`main.ts` (Node 22) copies `POST.json` from the repository root to `$MAKEFUN_OUTPUT_DIR` (fallback `/output`).

```sh
mkdir -p /tmp/out-spot && MAKEFUN_OUTPUT_DIR=/tmp/out-spot node main.ts
cat /tmp/out-spot/POST.json
```

## How to post

1. Take the play code from the make.fun play-code route for this competition (GET `/api/competitions/u-tina-spotlight-crisxai5-ai-crypto-expert-on-x-7c1ed9ad/play-code`) and put it in place of the `[PLAY-CODE …]` placeholder in `POST_DRAFT.txt`.
2. Post `crisxai5-spotlight.png` from a public X account with the draft text, before the deadline (27 Nov 18:35 WIB).
3. Copy the post's link (Share → Copy link) and write it into `POST.json` as `{"url": "https://x.com/<handle>/status/<id>"}`.
